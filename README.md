🎯 關於我 / About
從事工程多年，由前線地盤到項目管理，深深體會到工程行業數碼化嘅落後。 大灣區基建如火如荼，但好多公司仲係用人手做重複性文書工作。

我相信：工程人嘅時間，應該用喺解決工程問題，唔係用喺對齊同排版。

呢度嘅每一個工具，都係從真實地盤痛點出發，喺多個 GBA 工程項目中實戰驗證過。 唔係玩具項目 — 係每日都用緊嘅生產力工具。
